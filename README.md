# Чистота в доме · Екатеринбург

Сайт клининговой компании на HTML, CSS, JavaScript и PHP без CMS. Полноэкранный первый экран, выбор услуг, анимация при прокрутке, FAQ, форма заявки и защищённая админка.

- **Исходники:** ветка `main`.
- **Демонстрация:** [kibosh13.github.io/cleaning-ekb](https://kibosh13.github.io/cleaning-ekb/), ветка `gh-pages`.
- **Стек боевого сайта:** PHP 8.2+; JSON-файл с публичным контентом; JavaScript без библиотек.

## Структура

```text
app/                 PHP-шаблоны и общие функции
public/              Единственный публичный корень боевого сайта
  assets/            CSS, JavaScript, иконка и изображения
  api/               Серверная форма заявки и CSRF-токен
  admin.php          Админка с журналом заявок и редактором сайта
  uploads/           Загружаемые фото; не включаются в Git
  index.php          Маршруты, robots.txt, sitemap.xml и HTTP 404
scripts/
  setup-admin.php    Создание хеша пароля владельца через CLI
  export-preview.php Экспорт безопасной статической демонстрации
  publish-demo.sh    Обновление только изменившихся файлов gh-pages
config.example.php   Пустые настройки; секретов нет
nginx.example.conf   Пример конфигурации PHP-хостинга
data/content.json   Тексты, цены, порядок блоков и настройки формы
data/leads/        Закрытый журнал заявок, создаётся при первой заявке
```

`config.local.php`, `.env*`, пользовательские загрузки, временные ограничители запросов, базы данных, зависимости, сборки и архивы исключены из Git. Данные заявок не сохраняются в репозитории. Адрес почты и реквизиты в публичном контенте предоставлены для размещения на сайте.

## Возможности статической демонстрации

Работают адаптивная вёрстка, выбор услуги и фотографии, фильтры, FAQ, диалоги и проверка заполнения формы. Основная кнопка — «Заказать уборку». В статической демоверсии отправка отключена: письмо не создаётся, почтовая программа не открывается, успешный приём заявки не имитируется.

На боевом PHP-сайте эта кнопка сохраняет заявку в закрытом журнале админки. Почта и Telegram могут дублировать уведомления. При истечении сессии токен формы обновляется автоматически. Повтор той же заявки после сетевой ошибки использует прежний идентификатор, чтобы не создавать дубликат.

**В демоверсии отключены:**

- PHP, серверные API, сессии и выдача CSRF-токенов;
- вход в админку, изменение контента и загрузка фотографий;
- автоматическая доставка заявок на почту или в Telegram;
- сохранение заявок, серверная авторизация и база данных;
- Метрика и подтверждение боевого домена в Вебмастере.

PHP-файлы, приватная конфигурация и runtime-данные в `gh-pages` не публикуются.

## Индексация

**Демонстрация:** все HTML-страницы, включая документы и 404, содержат `noindex,nofollow,noarchive`; дополнительно опубликован `robots.txt` с `Disallow: /`. Для проекта, расположенного в подпапке GitHub Pages, основное ограничение — meta robots на каждой странице. Корневой robots.txt аккаунта и другие проекты пользователя не меняются. Демонстрационный sitemap не создаётся.

**Боевой PHP-сайт:** главная и документы содержат `index,follow`. Динамический `/robots.txt` разрешает публичные страницы и закрывает `/admin.php`, `/api/` и `/uploads/`. `/sitemap.xml` и canonical используют реальный `base_url` из приватной конфигурации. Админка и ошибки остаются `noindex`.

Экспорт демонстрации не переносит запрет индексации в боевой движок и не читает `config.local.php`.

## Локальный запуск PHP-сайта

Нужны PHP 8.2+ с `mbstring`, `fileinfo`, `session`, `json`; для Telegram — `curl` и TLS.

```sh
php -S 127.0.0.1:8000 -t public public/router.php
```

Для боевого запуска:

1. Настройте HTTPS и корень домена **строго на `public/`**.
2. Скопируйте `config.example.php` в `config.local.php` и заполните `base_url`.
3. Создайте вход через `php scripts/setup-admin.php admin`. Для хостинга без SSH можно положить SHA-256 случайного 64-символьного кода в `data/admin-setup.sha256`. Владелец вводит исходный код, логин и собственный пароль на `/admin.php`. Код используется один раз.
4. В админке откройте «Форма заявки», включите приём и сохраните изменения. Журнал принимает заявки без настройки почты. Почта и Telegram настраиваются отдельно в приватной конфигурации как дополнительные уведомления.
5. Проверьте перенесённые из материалов заказчицы прайсы и состав работ; заполните недостающие сведения в проектах документов.
6. Если нужна аналитика, укажите свой номер Метрики и код Вебмастера. Аналитика загружается только после согласия посетителя.

Подробности: [инструкция](ИНСТРУКЦИЯ.txt). Изображения созданы для проекта и являются иллюстрациями, а не кейсами заказчика; [промпты и список файлов](ИЗОБРАЖЕНИЯ.txt).

## Обновление исходников и демонстрации

```sh
# Находясь в main, измените необходимые исходные файлы, затем:
git add <изменённые-файлы>
git commit -m "Описание изменения"
git push origin main
bash scripts/publish-demo.sh
```

Скрипт требует чистую `main`, PHP, `rsync`, Git и авторизацию `gh`. Он экспортирует свежую демонстрацию во временную игнорируемую папку, подтягивает существующую `gh-pages` через `--ff-only`, сравнивает файлы по содержимому и коммитит только изменения. Неизменившиеся изображения не перезаписываются; ZIP/TAR-архивы не создаются. Если демонстрация уже актуальна, нового коммита и отправки не происходит. Чужая история не перезаписывается, `--force` не используется.

Публикация GitHub Pages настроена из корня ветки `gh-pages`. Результат сборки доступен в разделе Actions репозитория.

## Согласование перед боевым запуском

Пять услуг, 77 пунктов работ, 41 строка основных прайсов, 18 дополнительных услуг, пять FAQ и акция с возвратом 10% перенесены из 23 файлов заказчицы от 29.10.2026. Сводные цены, тарифы за м² и абонементы сохранены отдельно; точный автоматический калькулятор не подменяет оценку объёма работ. В форме добавлены тип помещения, диапазон площади и удобное время уборки; эти поля передаются в уведомление и описаны в согласии. Для сертификата помещение и площадь не требуются. Сохраняется одна финальная кнопка заказа.

В «Заявках» можно искать по имени, телефону и услуге, фильтровать по статусу, открывать карточки, записывать комментарии и удалять заявки. Данные хранятся за пределами веб-корня. PHP нужны права записи в `data/` и `public/uploads/`. Сохраняйте резервные копии `data/` и загрузок вне веб-корня. При обновлении сохраняйте рабочие `data/content.json`, `data/admin.json`, `data/leads/`, `config.local.php` и загруженные фото.

Редактор управляет текстами, фотографиями, контактами, SEO, услугами и таблицами цен, акциями, этапами, отзывами, работами, FAQ, формой, документами и порядком блоков. Дополнительный блок можно добавить с текстом и фотографией. Шаблон, стили и настройки инфраструктуры меняются в исходниках или панели хостинга.

Официальная документация: [публикация из ветки GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing).
